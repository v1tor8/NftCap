# NftCap

Turns on-screen alerts for crypto transactions, order book updates, market events in real-time for cryptocurrency traders and investors.

The key benefits of using NftCap include:

- Turns on-screen alerts for crypto
- transactions, order book updates, market
- events in real-time for cryptocurrency

## Key Features

- Turns on-screen alerts for crypto
- transactions, order book updates, market
- events in real-time for cryptocurrency

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftCap.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

NftCap is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
